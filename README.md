# Mintlify Landing Page

A desktop-first documentation website landing page inspired by the official Mintlify website.  
Built using **only HTML and CSS** (No JavaScript, No TailwindCSS, No frameworks).

**Assignment:** Chai Aur Code

---

## ✨ Sections Included

- Top Navigation Bar
- Hero Section
- Trusted By (Logos Grid)
- Built for the Intelligence Age Section
- Feature Highlights (Video Preview Cards)
- Enterprise Reinvention Section
- Customer Story (Anthropic)
- Enterprise Logos Row
- Customer Story Cards (3 Case Studies)
- Final Call-To-Action
- Footer (Multi-column layout with social links)

---

## 🛠 Tech Stack

- HTML5 (Semantic Markup)
- CSS3 (Flexbox + Grid + Custom Properties + `lab()` Colors)
- Google Fonts (Inter)

No JavaScript  
No CSS Frameworks  
Desktop-only layout

## 🚀 How to Run

```bash
git clone https://github.com/VinayakLambade22/Mintlify-Landing-Page.git

cd Mintlify-Landing-Page
```

**Open the HTML file**

- Navigate to the project directory
- Double-click `index.html` to open in your default browser
- Or right-click → Open with → Choose your preferred browser
